# Deployable Foundation and Accounts Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a white-label, Docker-deployable web application in which a user can register with verified email, sign in, reach a server-protected application shell, recover a password, and permanently delete the account.

**Architecture:** Use a Next.js 16 modular monolith with server components for protected pages, Better Auth backed by Drizzle/PostgreSQL for identity, and a pg-boss worker for durable SMTP email delivery. Load public branding and policy from strict YAML at process startup, load secrets from strict environment validation, and ship the app and worker from one Docker image with different commands.

**Tech Stack:** Node.js 24.x, pnpm 12.5.1, Next.js 16.3.6, React 19.3.0, TypeScript 7.0.2, Better Auth 1.7.5, Drizzle ORM 0.45.3, PostgreSQL 16, pg-boss 12.33.6, Zod 4.6.5, YAML 2.9.1, Nodemailer 10.0.10, Vitest 5.0.1, Testing Library 16.3.3, Playwright 1.63.0, Tailwind CSS 4.3.3.

**Spec:** `docs/superpowers/specs/2026-09-23-ai-companion-web-app-design.md`

## Global Constraints

- The deployer provides and pays for the model backend; model integration begins in Phase 3.
- The instance supports public registration, and the deployer can disable new registration.
- Users never configure a provider, endpoint, API key, temperature, or model.
- Use a modular monolith; do not introduce separately deployed business microservices.
- PostgreSQL is the only required stateful dependency.
- The supported deployment shape is `app + worker + postgres`.
- Public non-secret configuration lives in `app.config.yml`; secrets live in environment variables.
- Missing or invalid required configuration prevents startup with a specific error.
- Private content and secrets are not written to operational logs.
- Use server-side session validation for every protected page and mutation; a cookie-existence check is never authorization.
- The application must remain deployable and testable at the end of every task.

## Review Focus

- A syntactically valid but semantically invalid YAML file, an unknown key, or a missing secret must stop startup and identify the exact field.
- Closing registration must reject a direct `POST /api/auth/sign-up/email`, not merely hide the registration page.
- Signing up an already registered email must return the same public response shape as a new sign-up and must not reveal account existence.
- A forged session cookie must not grant access to `/app`, `/account`, or any protected mutation.
- A transient SMTP failure must retain the email job for retry and expose unhealthy worker state without rolling back an already-created account.

import { z } from "zod";

const publicPath = z.string().startsWith("/");
const absoluteOrMailtoUrl = z.string().refine(
  (value) => value.startsWith("https://") || value.startsWith("mailto:"),
  "must use https:// or mailto:",
);

export const publicAppConfigSchema = z
  .object({
    branding: z
      .object({
        name: z.string().trim().min(1).max(80),
        description: z.string().trim().min(1).max(200),
        logoPath: publicPath,
        faviconPath: publicPath,
        primaryColor: z.string().regex(/^#[0-9A-Fa-f]{6}$/),
      })
      .strict(),
    registration: z
      .object({
        open: z.boolean(),
        maxAttemptsPerHourPerIp: z.number().int().min(1).max(100),
      })
      .strict(),
    links: z
      .object({
        privacyUrl: absoluteOrMailtoUrl,
        termsUrl: absoluteOrMailtoUrl,
        supportUrl: absoluteOrMailtoUrl,
      })
      .strict(),
  })
  .strict();

const booleanString = z
  .enum(["true", "false"])
  .transform((value) => value === "true");

export const secretConfigSchema = z
  .object({
    NODE_ENV: z.enum(["development", "test", "production"]),
    DATABASE_URL: z.string().url().startsWith("postgresql://"),
    BETTER_AUTH_SECRET: z.string().min(32),
    BETTER_AUTH_URL: z.string().url(),
    SMTP_HOST: z.string().min(1),
    SMTP_PORT: z.coerce.number().int().min(1).max(65535),
    SMTP_SECURE: booleanString,
    SMTP_USER: z.string().min(1),
    SMTP_PASSWORD: z.string().min(1),
    SMTP_FROM: z.string().min(3),
  })
  .strict();

export type PublicAppConfig = z.infer<typeof publicAppConfigSchema>;

export interface SecretConfig {
  nodeEnv: "development" | "test" | "production";
  databaseUrl: string;
  betterAuthSecret: string;
  betterAuthUrl: string;
  smtp: {
    host: string;
    port: number;
    secure: boolean;
    user: string;
    password: string;
    from: string;
  };
}

export interface RuntimeConfig {
  public: PublicAppConfig;
  secret: SecretConfig;
}

- [ ] **Step 4: Implement one cached configuration loader**

Create `src/server/config/load-config.ts`:

```ts
import { readFile } from "node:fs/promises";
import path from "node:path";
import { parse } from "yaml";
import {
  publicAppConfigSchema,
  secretConfigSchema,
  type RuntimeConfig,
} from "./schema";

export interface LoadRuntimeConfigInput {
  configPath?: string;
  env?: NodeJS.ProcessEnv | Record<string, string | undefined>;
}

function formatIssues(label: string, issues: { path: PropertyKey[]; message: string }[]) {
  return issues
    .map((issue) => `${label}.${issue.path.join(".") || "<root>"}: ${issue.message}`)
    .join("; ");
}

export async function loadRuntimeConfig(
  input: LoadRuntimeConfigInput = {},
): Promise<RuntimeConfig> {
  const env = input.env ?? process.env;
  const configPath =
    input.configPath ??
    env.APP_CONFIG_PATH ??
    path.join(process.cwd(), "app.config.yml");

  const source = await readFile(configPath, "utf8").catch((error: unknown) => {
    const message = error instanceof Error ? error.message : String(error);
    throw new Error(`Unable to read app config at ${configPath}: ${message}`);
  });

  const publicResult = publicAppConfigSchema.safeParse(parse(source));
  if (!publicResult.success) {
    throw new Error(formatIssues("app.config.yml", publicResult.error.issues));
  }

  const secretResult = secretConfigSchema.safeParse({
    NODE_ENV: env.NODE_ENV ?? "development",
    DATABASE_URL: env.DATABASE_URL,
    BETTER_AUTH_SECRET: env.BETTER_AUTH_SECRET,
    BETTER_AUTH_URL: env.BETTER_AUTH_URL,
    SMTP_HOST: env.SMTP_HOST,
    SMTP_PORT: env.SMTP_PORT,
    SMTP_SECURE: env.SMTP_SECURE,
    SMTP_USER: env.SMTP_USER,
    SMTP_PASSWORD: env.SMTP_PASSWORD,
    SMTP_FROM: env.SMTP_FROM,
  });
  if (!secretResult.success) {
    throw new Error(formatIssues("environment", secretResult.error.issues));
  }

  const secret = secretResult.data;
  return {
    public: publicResult.data,
    secret: {
      nodeEnv: secret.NODE_ENV,
      databaseUrl: secret.DATABASE_URL,
      betterAuthSecret: secret.BETTER_AUTH_SECRET,
      betterAuthUrl: secret.BETTER_AUTH_URL,
      smtp: {
        host: secret.SMTP_HOST,
        port: secret.SMTP_PORT,
        secure: secret.SMTP_SECURE,
        user: secret.SMTP_USER,
        password: secret.SMTP_PASSWORD,
        from: secret.SMTP_FROM,
      },
    },
  };
}

let runtimeConfigPromise: Promise<RuntimeConfig> | undefined;

export function getRuntimeConfig(): Promise<RuntimeConfig> {
  runtimeConfigPromise ??= loadRuntimeConfig();
  return runtimeConfigPromise;
}
```

export interface ReadinessDependencies {
  checkDatabase(): Promise<void>;
  checkWorker(): Promise<void>;

export async function checkReadiness(dependencies: ReadinessDependencies) {
  const [database, worker] = await Promise.allSettled([
    dependencies.checkDatabase(),
    dependencies.checkWorker(),
  ]);
  const checks = {
    database: database.status === "fulfilled" ? "ok" : "error",
    worker: worker.status === "fulfilled" ? "ok" : "error",
  } as const;
  return {
    ready: checks.database === "ok" && checks.worker === "ok",

  };
}

  db: Database,
  worker: string,
  newerThan: Date,
): Promise<void> {
  const [row] = await db
    .select({ worker: workerHeartbeat.worker })
    .from(workerHeartbeat)
    .where(
      and(
        eq(workerHeartbeat.worker, worker),
        gt(workerHeartbeat.updatedAt, newerThan),
      ),
    )
    .limit(1);
  if (!row) throw new Error("worker heartbeat is stale");
}
```

interface MailpitAddress {
  Address: string;
}

interface MailpitSummary {
  ID: string;
  Subject: string;
  To: MailpitAddress[];
}

interface MailpitList {
  messages: MailpitSummary[];
  Messages?: MailpitSummary[];
}

interface MailpitMessage {
  Text: string;
}

export async function clearMailbox(): Promise<void> {
  await fetch("http://127.0.0.1:8025/api/v1/messages", { method: "DELETE" });
}

export async function waitForActionUrl(
  recipient: string,
  subjectPrefix: string,
): Promise<string> {
  const deadline = Date.now() + 10_000;
  while (Date.now() < deadline) {
    const response = await fetch("http://127.0.0.1:8025/api/v1/messages");
    const body = (await response.json()) as MailpitList;
    const messages = body.messages ?? body.Messages ?? [];
    const summary = messages.find(
      (message) =>
        message.Subject.startsWith(subjectPrefix) &&
        message.To.some((address) => address.Address === recipient),
    );
    if (summary) {
      const detailResponse = await fetch(
        `http://127.0.0.1:8025/api/v1/message/${summary.ID}`,
      );
      const detail = (await detailResponse.json()) as MailpitMessage;
      const match = detail.Text.match(
        /http:\/\/127\.0\.0\.1:3000\/[^\s]+/,
      );
      if (!match) throw new Error(`No local action URL in email ${summary.ID}`);
      return match[0];
    }
    await new Promise((resolve) => setTimeout(resolve, 250));
  }
  throw new Error(
    `Timed out waiting for ${subjectPrefix} email to ${recipient}`,
  );
}
```

  without rebuilding the image.
